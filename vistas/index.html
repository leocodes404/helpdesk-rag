HelpDesk RAG: Plataforma web para gestión inteligente de tickets y soporte TI

Las organizaciones enfrentan un flujo constante de incidencias tecnológicas (equipos, redes, accesos y software) que requieren un registro detallado con evidencias, clasificación precisa, asignación supervisada y seguimiento técnico. Aunque existe documentación técnica e historial de soluciones, los técnicos necesitan acceder a esta información rápidamente manteniendo la trazabilidad de las decisiones tomadas. Para optimizar este flujo, se requiere implementar una plataforma web centralizada de gestión de tickets (con control de usuarios, estados, auditoría y dashboards) potenciada con Inteligencia Artificial (PLN y RAG) que clasifique automáticamente las solicitudes y recomiende soluciones precisas basadas en la base de conocimiento institucional.
